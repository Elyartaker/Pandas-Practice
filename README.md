# Pandas Guide

A hands on **pandas** mini-project focused on exploring multiple real and synthetically generated datasets while practicing core data preprocessing and data cleaning techniques.

## Target Audience & Purpose

This repository is designed as a **refresher and practice resource** rather than a ground up tutorial:
- **Intended for:** Learners who already have at least a **basic understanding of pandas** (e.g., Series/DataFrames, indexing, reading files) and want to reinforce key workflows, as well as experienced users looking for a quick practical refresher.
- **Not intended for:** Complete beginners with zero prior familiarity with pandas.

## What’s Inside

- **Notebooks (`notebooks/`):** Exploratory notebooks covering multiple real and generated datasets, focusing on inspection, preprocessing, and basic data cleaning.
- **Datasets (`notebooks/data/`):** The real and generated datasets used across the notebooks.
- **Documentation (`pandas_guide.pdf`):** Full explanations and walkthroughs—written in **Persian**.
